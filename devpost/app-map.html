Follow one plate

1 / Tap Chicken

index.html #pantry contains semantic ingredient buttons created by src/app.mjs. A click calls act({type:'TOGGLE', id:'chicken'}). Number keys take the same path.

2 / Settle time, then change state

act → settle → dispatch. Elapsed time is deducted first, so a click cannot rescue an already-expired ticket. The pure engine toggles Chicken in selected and enforces four ingredients maximum.

3 / Draw the plate

render updates pressed states and shows owned SVG food from src/art.mjs. The recipe and exclusions come from src/content.mjs, not a model or API.

4 / Ring SERVICE!

dispatch(SERVE) → judgePlate compares selected IDs with required, optional and forbidden sets. Missing, excluded or unrequested ingredients score zero. Correct plates receive base, flavor and speed points, multiplied by the prior streak.

5 / Reaction or receipt

The engine enters feedback; clocks freeze. The screen explains the result and announces it accessibly. Next Ticket advances the deck and stage. Service expiry ends the run; restart creates fresh state.

The useful boundaries

Piece Owns Does not own
content.mjs Fictional tickets and ingredient IDs Real dietary or allergy advice
engine.mjs State, timing, scores DOM, sound, network, wall clock
app.mjs Inputs, rendering, focus, clock, optional sound Accounts, storage, paid APIs
build.mjs Known module + asset inlining Arbitrary remote imports
server.mjs Local allowlisted preview Private files or public deployment

First place to inspect

  • Wrong points or expiry: engine.mjs and tests/engine.test.mjs.
  • Wrong joke or ingredient: content.mjs. Keep required/optional/forbidden sets disjoint.
  • Button or pause trouble: app.mjs handlers and scripts/browser-test.mjs.
  • Clipped text: responsive styles.css. Do not shrink touch targets to fix layout.
  • Missing offline resource: scripts/build.mjs. Keep the game self-contained.

One safe experiment, later

Expanded service — October 9 candidate

Reference route, not a completed founder code tour. Restored from 535a2d9; expansion branch build/chaos-star-expansion. This snapshot can drift.

  1. Switch table: app.mjs renderTables → act → updateGame → service.mjs dispatchService(SWITCH_TABLE). Other tables keep their own plate, prep and pan.
  2. Settle every clock: service.mjs TICK advances all live tables only as far as the earliest deadline. Feedback and pause stop every table. Serving at a deadline cannot score.
  3. See the result: serviceView feeds app.mjs render. Every fourth issued ticket pays double for a valid plate. Bonus-perfect plates unlock a Chaos Star rim, Golden Plate and Chef Crown at 1/3/5. Rewards reset each shift.

Menu and cooking methods: content.mjs COOKING. Phone tray: app.mjs trayFor (eight visible choices including required and bonus items). Intro/music: showtime.mjs. Safe tutorial: engine.mjs tutorial flag; READY never burns. No backend, stored identity, downloads or paid services.

Practice to reuse: visible timers must match the engine's actual deadline. Review found a table could show 52 seconds although prep expires after 16. The rail now displays the earlier deadline. Test the rule and the displayed promise together.

Run: npm test; npm run check; npm run build; npm start. Interaction harnesses accept JSDOM_MODULE; browser scripts accept PLAYWRIGHT_MODULE and CHROMIUM_PATH. Browser layout and physical audio/controller acceptance are separate from rule tests.

Known limits

No scores persist. Practice and timed scores are different. A hidden tab pauses; return never resumes automatically. Canonical artwork licensing, public release, physical iPhone/Safari and actual enjoyment remain human checks. See README and devpost/verification.md.

Chef mode: follow one plate

Welcome checkbox and difficulty button → createGame → prep station. Ingredient buttons and PREP actions track two tasks per item. HANDOFF locks the selection. COOK / STOP_COOK update one fictional pan; TICK enforces readiness, burning and deadlines. HANDOFF opens plating; PLATE reveals each component. SERVE uses the existing ticket judge. Feedback → NEXT resets the station.

Rules and clocks: src/engine.mjs. Stable controls, gauges and sound cues: src/app.mjs. Pantry order: pantryFor(seed, ticket index), also used by keyboard numbers. No backend or runtime AI. Tests: tests/chef.test.mjs and scripts/chef-dom-test.mjs. One pan now; simultaneous cooking later. Visual and phone acceptance remain open.
